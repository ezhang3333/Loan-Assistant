## Loan Match

GCP hosted loan matching application that is trained and based on these 2 datasets:

- https://www.kaggle.com/datasets/amineipad/loan-approval-dataset
- https://www.kaggle.com/datasets/puneetpainuly/bank-loan-dataset

Some cool features include:

1. **Loan optimizer and pathway planner** which indicates weaknesses in a user's profile as a loan applicant and provides feasible steps to improvement
2. **Bank approval heatmap** that matches based on banks in a user's area that have approved users of similar loan profiles
